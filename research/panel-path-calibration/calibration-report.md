# C1 有限样本校准研究结果

## 结论

独立验证通过，但仅限预注册的已知参数模拟环境。不能据此发布 v1.82，不能把这些临界值用于真实数据，也不能把旧 Gaussian sup-t 验证从失败改为通过。

本研究完成40,000个独立模拟面板：null/alternative各10,000个训练面板，另各10,000个验证面板。36项验证覆盖率为94.68%–96.32%，均在原门槛93.5%–96.5%内；6项 difference 零假设拒绝率为3.68%–4.83%，均在3.5%–6.5%内。6项预注册的检验力提升条件全部通过。

## 方法与限制

保持原估计器、标准误构造和模拟 DGP；仅从独立训练面板中得到学生化路径误差的经验临界值。每项采用 null 与 alternative 训练95%分位数的较大值，在读取验证结果前锁定。不使用真实数据未知参数的估计值，因此这是 oracle 诊断，不是可直接应用的方法。没有生成新的正式 p 值。

每个面板完整重估25个 horizon；三个 horizon 窗口共享同一个面板，不计为三个独立面板。每个阶段、设计首个面板均与生产拟合器核对系数和方差。研究完成时验证6个冻结文件字节不变，并复核预注册、执行程序、依赖文件及锁定临界值哈希未改变。

训练种子1822001/1822002；验证种子1823001/1823002；PCG64。用时154.12秒。未运行内层Gaussian抽样，不能与此前含10,000次内层抽样的研究直接比较运行量。

这是本地执行前登记，不是公开第三方时间戳预注册。已知此前失败结果，所以只对新的训练/验证实验作事前约束。
