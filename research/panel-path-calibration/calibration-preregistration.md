# Panel LP 有限样本校准研究：预注册 C1

登记日期：2026-09-15。状态：本地、执行前登记，不是外部时间戳注册。

## 已知信息与范围

已知 v1.82 的旧模拟失败，因此本研究不是对旧结果的事前注册。旧结果、正式系数、标准误、逐点区间、组成诊断及发布门槛全部保留。本研究不写入正式数据目录，不授权发布。

首先回答一个有限问题：在原有已知参数 DGP 内，用训练模拟校准的 max-t 临界值能否迁移到独立模拟？这是依赖已知 DGP 的 oracle 诊断，不是可用于真实数据的 bootstrap，也不是 Gaussian sup-t 的直接替代。

## 固定设计

沿用 path-simulate.py 的 T=130、8 国、rho=.4、100 burn-in、两种相关共同冲击、共同/组别/个体创新、原 null 和 alternative 系数、国家固定效应及 pmax=5。每个模拟面板完整重估 h=0..24，H=6/12/24 为同一面板子路径，不重复计作独立面板。原生成器与拟合器文件的 SHA256 随执行记录。

训练：null 和 alternative 各 10,000 个面板；种子 1822001、1822002。
验证：null 和 alternative 各 10,000 个新面板；种子 1823001、1823002。
随机算法 PCG64；固定 batch=10。不复用旧模拟，不根据中间结果提前停止。

每个 H×shock×path（共18项）记录 M=max_h abs((estimate-truth)/frozen-form-SE)。分别取两种训练设计 M 的95% higher分位数，取两者较大值作为唯一候选临界值，并下限约束为1.959963984540054。不搜索乘数或其他候选。训练临界值在读取验证结果前单独落盘并记录哈希。

验证置信带为 estimate ± c×SE，拒绝规则为 max abs(estimate/SE)>c。只报告拒绝率，不虚构 Gaussian 或 bootstrap p 值。group 响应在两种设计都非零，其拒绝率为 power；只有 null 的 difference 路径可称 size。

## 不可调整的决策

每个验证设计、H、shock、path 的覆盖率均需在[.935,.965]；每个 null difference size 需在[.035,.065]；每个 alternative difference power 至少高于对应 null size .05。完整报告36行，包括失败行；报告二项比例标准误。任一失败即 C1 失败，不删设计、不调临界值、不重抽种子。数值错误停止并报告，不丢弃面板。

训练组别取最大临界值可能过度覆盖，也按原有双侧门槛判定失败。即使全部通过，也只能称本 DGP 内独立验证通过；不能称普遍有限样本有效，不能启用正式路径推断。

## 后续边界

C1 后另行预注册持久性、样本长度、非正态与异方差等压力测试；若要构造真实数据可用的重抽样方法，需要明确联合动态 DGP、跨月/跨国依赖、重新估计与 studentization 方案和独立实现，不能把 oracle 临界值贴到真实路径上。旧 v1.82 gate 继续 blocked。

参考定位：[MOPM 官方实现](https://github.com/jm4474/Confidence_Bands)提供一般 sup-t 框架；本次 oracle 校准是独立研究设计，不声称为其 panel 专用方法或作者复现。
