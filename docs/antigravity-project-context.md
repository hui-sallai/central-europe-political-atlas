## 1. Project Identity & Mission

- **Official name:** Central Europe Political Atlas v2.0 (`中欧政治经济平台`)
- **Production URL:** https://hy-central-europe-analysis.org/
- **Repository:** https://github.com/hui-sallai/central-europe-political-atlas
- **Nature:** Bilingual (Simplified Chinese at `/`, English at `/en/`), non-commercial, research-oriented political economy platform deployed as a static Next.js export (`output: "export"`) to GitHub Pages via `.github/workflows/deploy-pages.yml`.
- **Ten-country coverage (fixed project scope):** Germany, Poland, Czechia, Slovakia, Hungary, Austria, Slovenia, Croatia, Romania, Serbia. Do not add or remove countries without a separate owner decision.

## 2. Technical Architecture

- **Stack:** Next.js 16 (App Router, static export, `trailingSlash: true`), React 19, TypeScript, Tailwind CSS 4 (`@layer base` for element defaults).
- **Runtime dependency constraint:** Only `next`, `react`, `react-dom` in `dependencies`. Charts remain hand-written SVG (`src/components/ResearchTimeSeriesChart.tsx`, etc.).
- **Primary routes (mirrored in `/` and `/en/`):**
  - `/` — Map-first homepage (`HomeResearchMap`)
  - `/countries/`, `/countries/[slug]/` — Country research hubs & institutional timelines
  - `/politics/`, `/politics/<country>/` — Ten-country parliamentary election archive, historical comparisons, and institutional comparison (`PoliticalLanding`, `PoliticalExplorerAlpha`, `PoliticalBallotExplorer`, `InstitutionComparison`)
  - `/data/` — Economic Data Explorer (`DataExplorerV11`, `NationalComparisonWorkspace`, annual/monthly/quarterly/macro drivers)
  - `/map/` — Factual regional comparison map (`ComparativeSpatialWorkbench`)
  - `/workspaces/`, `/workspaces/[id]/`, `/workspaces/<theme>/` — Question-first and thematic research workspaces (industrial policy, FDI, energy, EU funding)
  - `/models/` — Quantitative research workbenches (transparent models, panel econometrics, trade network, VAR, Local Projections, Panel LP, event window)
  - `/scenarios/` — Conditional scenario presets
  - `/news/` — Political Economy Event Library
  - `/notebook/` — Browser-local Research Notebook (`ResearchNotebookPage`)
  - `/methodology/`, `/legal/`, `/privacy/` — Methods, downloads, legal/privacy disclosures
- **Directory roles:**
  - `src/app/(zh)/` & `src/app/(english)/en/` — Bilingual App Router entrypoints
  - `src/components/` — Presentation and workbench components
  - `src/lib/` — Typed adapters, registries, and analytical engines
  - `src/data/` — Canonical research data and frozen outputs (DO NOT EDIT directly)
  - `public/research-data/` — Exported public research mirrors (regenerated by `scripts/export-research-data.mjs`; DO NOT EDIT by hand)
  - `docs/` & `docs/political-data/` — Methodology notes, iteration reports, admission records, and source-closure checkpoints
  - `tests/ui/` & `tests/tooling/` — Playwright UI/accessibility/visual tests and Node tooling tests

## 3. Non-Negotiable Data & Research Governance

1. **Never edit canonical data or frozen research:** `src/data/**`, `public/research-data/**`, `src/data/release.json`, hash-registered engines (`varEngine.ts`, `timeSeriesTransforms.ts`, `varSpecifications.ts`, `networkEngine.ts`), and frozen research cohorts (e.g. D4 17-election sample, VAR dynamic-response publication gate).
2. **Preserve research semantics:**
   - Missing data is not zero (`—`, never `0`).
   - Officially published percentages remain distinct from derived shares (preserve denominators).
   - Never pool distinct ballots, rounds, tiers, general/minority ballots, or separate legislative chambers.
   - Never infer historical party continuity from similar names or split coalitions without source-backed allocation.
   - Preserve Hungary 1998 valid-round composite semantics and Germany 1990 eastern/western separate thresholds.
3. **UI wording & language gates:** No causal or predictive wording beyond published methodology. All UI changes must pass `pnpm ui-language:qa`, `pnpm i18n:validate`, `pnpm seo:validate`, and `pnpm ui:regression-validate`.
4. **Source-closure exact-hash UI amendment gate:**
   - `pnpm political-source-closure:validate --checkpoint` checks all files under `src/data`, `public/research-data`, `src/app`, `src/components`, and `src/lib` against `docs/political-data/source-closure/frozen-baseline.json` and `docs/legal-security/ui_governance_amendments.json`.
   - Any modified/added presentation file under `src/(app|components|lib)/` requires an exact SHA-256 record in `docs/legal-security/ui_governance_amendments.json` with all five `*_allowed` flags set to `false`.
   - **Never authorize an amendment on behalf of the owner.** Use `status: "pending_owner_approval"` or provide the exact-hash JSON block for owner approval before merge to `main`.
5. **Screenshot baseline policy:**
   - Baselines live in `tests/ui/__screenshots__/<platform>/<project>/` (`darwin` and `linux`).
   - `pnpm test:ui` uses `updateSnapshots: "none"`. Never weaken thresholds or silently overwrite baselines.
   - Linux baselines used by GitHub Actions are recorded via manual `workflow_dispatch` with `ui_baselines: record` (which never deploys).

## 4. Multi-Agent Division of Responsibilities

- **Claude Code:** Official data acquisition, source admission, legal/institutional evidence, canonical data normalization, reconciliation, data generators, and data validation.
- **OpenAI Codex:** Analytical interfaces, typed research adapters, statistical visualizations, comparison engines, election-specific analytical components, and quantitative research features.
- **Google Antigravity:** Overall product experience, information architecture, navigation, responsive design (`1440px`, `1024px`, `768px`, `390px`), visual presentation, browser-based user testing, WCAG accessibility, interaction consistency, frontend performance/rendering stability, and independent browser verification.
- **Shared-file coordination:** Do not edit `main` directly; work on an isolated branch (e.g. `ux/antigravity-*`). Avoid modifying Codex-owned analytical files (`PoliticalExplorerAlpha.tsx`, `politicalStores.ts`, `politicalExplorer.ts`, `politicalNational.ts`) without coordination; prefer dedicated presentation components and page wrappers, or write a focused handoff.
