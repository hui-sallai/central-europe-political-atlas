# Research Snapshot / 描述性研究包

本功能属于 v2.0 产品更新，不是新版本编号。没有修改版本号、冻结数据、正式样本、模型就绪状态或统计方法，也不启用正式推断。开发完成后按用户授权推送部署；实际部署状态以 CI 与线上核验为准。

## 使用

在数据浏览器、国家对比或区域地图中完成筛选后，点击“导出研究快照”。按钮显示准备、生成、下载或失败状态；加载数据或缺少必要 SORS 原始来源代码时停用。

支持：

- 年度视图：国家、指标、起止年份、最新值、历史层、SORS 层、搜索和排序。
- 高频视图：国家、指标、年份、历史层和排序；与现有可见表格一致，仅导出非空的合格观测。被排除的缺失月份不补零。
- 宏观驱动描述性视图：指标、范围、转换和历史层；预热、缺口、定义/制度阻断保持原状态及空值，共同序列保留适用范围。
- SORS 月度/季度独立视图：当前序列及全部可见时期；CSV 保留季度标签，图形按现有图表映射为季末月份。
- 国家对比：六项现有指标，每项使用两国同单位的最新共同年份；未匹配的两国单元格为空。不同指标的参考年份可能不同，不提供排名。
- 区域地图：当前国家/同层级比较、图层、年份、分级、区域高亮、项目行业/状态。高亮不是过滤，CSV 包含地图上全部区域（包括缺失区域）；项目图层导出当前可见项目。

分享链接保留上述视图状态。年度单指标图形使用筛选后的记录；地图研究包与普通地图导出共用同一个 SVG 生成入口及当前渲染图例，不另算分级。

## ZIP 内容

固定文件：`README.md`、`manifest.json`、`data.csv`、`sources.csv`、`citation.txt`、`view-url.txt`。

当前有可见单指标图形时增加 `figure.svg`；地图增加 `map.svg`。SVG 使用中性打印配色。没有图形时不伪造图形文件。

`manifest.json` 使用 `atlas-descriptive-snapshot-v1`，记录当前过滤/比较条件、国家、指标、时期范围、单位、行数、数据层、来源、可比性、缺失策略、方法边界、限制、引用和链接，以及地图图例、阈值、行政层级与 NUTS/NSTJ 归属。

`data.csv` 的 `source_id` 对应 `sources.csv`；相同来源元数据去重。保留官方/历史/SORS 层身份，SORS 原始代码、原始单位、原始值、标准化值及分段/跨国可比标记。未知来源字段留空，不推测采集时间或原始代码。空值为空，真实零值仍为零。

浏览器本地生成 UTF-8 ZIP32 STORE：CRC32、本地文件头、中央目录和结束记录；无新增运行时依赖，不向服务器上传视图。返回的 CSV/ZIP 不是模型结果包。

## 尚不支持与限制

不提供 PDF、正式 LP/Panel LP/VAR 结果包、模型估计、预测、因果或政策评价。研究包只归档当前已载入视图，不包含全站数据、原始来源全文或底层行政边界文件。

分享链接能复现筛选条件，不能锁定日后的官方数据修订；下载的 CSV 才是本次访问的观测副本。不同定义、单位、历史段、季度/月度和国家 CPI/HICP 不自动拼接。归档中没有的采集日期、完整查询字段等来源信息仍可能留空。按钮“已下载”表示浏览器已触发下载，不能证明用户最终保存了文件。
