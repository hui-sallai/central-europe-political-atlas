# v0.95 release audit

Audit date: 2026-08-19

## Public-page findings

| Page | Baseline issue | Release-candidate treatment |
| --- | --- | --- |
| Home | Current-stage text competed with the research purpose and primary entry points. | Reduced to purpose, scope, release status, five primary entries and citation. |
| Map | Technical history was more prominent than current factual-layer readiness. | Kept factual map status and public-display boundaries; historical QA remains in research records. |
| Countries | Useful coverage states were mixed with repeated implementation wording. | Retained concise country entry, coverage and research-status summaries. |
| Country | Research assets were present but model/project/event traces were not consistently exposed. | Added compact research snapshots and stable model links without duplicating the data workbench. |
| Data | The initial static document eagerly rendered multiple large dictionaries and QA tables. | Kept the country workbench primary and moved dictionaries, validation, regional and specialist panels behind on-demand controls. |
| Events | Formal events and project relations were visible but record citation was weak. | Added event citation and stable project trace links. |
| Models | Model cards were transparent but selected state and citations were not stable research interfaces. | Added URL state, output/model/source citations and validation blocking. |
| Scenarios | Traceability existed but result citation and validation blocking were incomplete. | Added stable result citation and explicit unavailable behavior for blocking validation failures. |
| Methodology | Version-by-version additions obscured current rules. | Reorganized into scope, sources, status, comparability, regional data, events, projects, models, scenarios, validation, limitations, changelog and citation. |

## Preserved research assets

- Canonical observations, indicators, sources and quality checks.
- Regional boundary, license, topology and display-gate evidence.
- Events, China-related project verification and exposure candidates.
- Transparent model cards, scenario definitions and observation traces.
- Historical QA records and machine-readable exports.

## Explicit release boundaries

- No new model, scenario, index, forecast or regional risk layer.
- No promotion of pending, sample or placeholder records to official status.
- No change to the GitHub Pages base path or existing public routes.
- Serbia regional comparison remains pending while national data remain public.
